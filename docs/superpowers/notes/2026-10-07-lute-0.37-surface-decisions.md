# Lute 0.37 — surface cleanup: decisions

Decision log for the 0.37 "surface cleanup" release (clean cutover, D6 of
`docs/design/architecture-direction.md`). Inputs: the authoring and IR surface
audits and four ground-truth scouts (2026-10-07), each claim re-checked
against code and corpus. The 0.37 spec is written from this note; where the
spec needs a detail this note leaves open, the spec decides and says so.

## Decided

| # | Decision | Evidence / notes |
|---|---|---|
| S1 | `shot` → **section** everywhere (AST, compiler, `addr` first segment, IR `shots`/`shotEntry`, docs). Optional stable id `## Title {#id}`; position stays the fallback. | The `## ` heading is an ordered document section (dsl 0.0.1 §6.3); IR `shotEntry` carries only `{shot, heading}`. |
| S2 | `::cut` → **`::cg`** (author and IR kind). `full` leaves core; see D2. | `cut` shows an event illustration (`staging.yaml`, `cutIn`); 2 corpus files. |
| S3 | Camera / framing / transition become **project-declared staging vocabulary** (like `emotion`); core keeps the slot, timing, subject check and capability, not members. Bespoke cinematics use a declared **sequence reference**. Concrete shapes: D1, D3. | `camera.moveX/moveY/zoom` are fixed 2D fields. `anchor` is already a project domain (`port`/`starboard` in corpus), so it is a named mark, not a coordinate. A project cannot declare directives today (only `enums:` members, `crates/lute-manifest/src/entities.rs`), so vocabulary rides on domain-typed core attrs. |
| S4 | Domain-standard abbreviations **stay**: `sfx`, `vfx`, `bg`, `os` (O.S.), `vo` (V.O.). The defect is only author-name vs IR-name mismatch (`bg` → `background`, `os` → `offscreen`, `vo` → `voiceover`); align the two. | `sound`/`effect` would lose the meaning. |
| S5 | `mono` stays (bare flag; `delivery=` is NOT revived — dsl 0.2.2 §D7 replaced it and `lute fix` still rewrites it, `fix.rs:219-242`). New rule: **only the effective POV may speak `mono`**, plus speakers the document allow-lists. Concrete rule: D8. `lute context` guidance states the same. | Effective POV = frontmatter `pov` over project `defaults.pov` (`meta/frontmatter.rs:252-280`). Census of 69 `mono` lines: 20 match the effective POV, 1 mismatches (`episodes/diner.lute:32`, `mira` under `pov: fixer`), 48 sit where no POV resolves (hollow-ward `nell`, lamplight / lighthouse-keeper `inspector`, lantern-academy `you`, …). |
| S6 | **Every line carries a `voiceKey`**, narration and monologue included. A key is a join, not a recording obligation; a project that does not voice narration has no asset for it. Remove the `Role::voiced()` gate. | Gate is one site: `crates/lute-compile/src/address.rs:343` (`ir.rs:777`). No Lute consumer exports a recording list, so no role setting is needed now; when one exists, its role filter lives there. Re-run `voice_key_collisions` (`E-DUP-VOICEKEY`) over the corpus — the check's scope grows. |

## Design (owner-approved 2026-10-07; `::auto` → `::actor` confirmed)

Principle: **an IR kind or field has the same name as the authored directive
or attribute that produces it.** That alone settles S4 (`bg`, `os`, `vo` in
the IR too) and the renames below.

| # | Surface | 0.37 shape |
|---|---|---|
| D1 | `::camera` | Attrs `focus` (cast reference, as today), `framing: {domain: framing}`, `move: {domain: cameraMove}`, `transition: {domain: transition}`; timing via the common stamp. `zoom`, `moveX`, `moveY`, `shake`, `reset`, `easing` are removed (a project expresses them as members, e.g. `move: shake`, `framing` default member for reset). At least one attr is required. IR `camera {focus?, framing?, move?, transition?}`. Camera persistence (save/restore) is **not** in 0.37: no runtime reads it yet. |
| D2 | `::cg` | Attrs `assetId` (required), `display: show|hide` (default `show`), `layout: {domain: cgLayout}` replaces `full`. Same `display` attr replaces `action` on `::video`. |
| D3 | `::sequence` (new) | `::sequence{name}` with `name: {domain: sequence}`; `wait` defaults `true`. IR `sequence {name}`. Bound characters are **not** in 0.37 (needs a per-member declaration shape that domains lack). |
| D4 | `::auto` → `::actor` | Attrs `character`, `anchor`, `action`, plus new `emotion: {domain: emotion}`, `costume: {domain: costume}`. An authored `emotion` updates stage emotion like a line's. IR kind `sprite` → `actor` for authored and injected records. |
| D5 | Media attrs | `::music{action}` → `playback` (domain `musicAction` → `musicPlayback`); `music.track` removed (use `assetId`); `sfx.name` removed (`sound` is the semantic name, `assetId` the concrete one); IR `vfx.vfxType` → `type`. |
| D6 | Lines | IR `role` values become `dialogue`, `narration`, `mono`, `os`, `vo`. Line `id=` removed. Every line gets `voiceKey` (S6). |
| D7 | Control | `::next{to}` → `::jump{to}`; `::mark{id}` → `::label{name}`; the one document-wide forward-label namespace is unchanged. Choice `label=` → `text=` (IR option `label` → `text`, locale rows too). `<match on>` → `<match subject>`. |
| D8 | `mono` rule | `E-MONO-POV`: a `mono` line whose speaker is neither the effective POV nor in the effective `monoSpeakers` (new defaultable frontmatter list). `E-MONO-NO-POV`: same, when no POV resolves. Component lines are checked at each `::use` site in the caller's context. Corpus migration declares the missing project `defaults.pov` (judgment, not codemod) and gives `diner.lute` `monoSpeakers: [mira]`. |
| D9 | Sections | `## Title {#id}`: optional trailing suffix, id unique per document (`E-SECTION-DUP`); the heading text excludes the suffix. IR `sections: [{section, heading, id?}]`. Section ids are identity only, not jump targets. |
| D10 | Rewards | Optional `<reward id>`, unique within its quest; IR `RewardEntry.id?`; source-map / model keys use the id when present, the declaration-index key otherwise. |
| D11 | Inline text modifiers | Inside content-line text only. `:name[text]` (span), `:name{attrs}` (leaf), `:name[text]{attrs}`. Core: `pause{s}` (leaf, seconds), `speed[…]{rate}` (span). Any other name must be a member of project domain `textStyle` (span, no attrs). Spans nest; `{{…}}` may sit inside a span; `\:` writes a literal colon. IR: `text` is the markup-stripped text (still carrying `{{…}}` markers); `segments` appears only when the line has a modifier: `[{text, styles?, rate?} | {pause}]`; `localeSegments {locale: segments}` likewise. `loc export` keeps the markup; merge rejects a translation whose modifier multiset differs from the source (`E-L10N-MODIFIERS`). `E-DUP-VOICEKEY` compares stripped text. |
| D12 | IR envelope / records | `addr` → `position` (fields that point at positions keep their names); `capabilityVersion` → `capabilitySnapshot` (IR, index, `lute context --json`); `recordKey` → `selectionKey`; every command gets `family` ∈ `content`, `staging`, `state`, `control`, `declaration`, `plugin` (first drafted as `category`, renamed because lore `<entry category>` already serializes a `category` field); the common stamp's `wait`, `duration`, `delay`, `at`, `timeline` move into one `timing` object (seconds), so `barrier`'s own `timeline` / `at` no longer collide; choice `timeoutSec` → `timeout` (seconds). Rust `Command::Other` → `Command::Plugin`. |
| D13 | Dead forms | Remove project `sequence:` key handling beyond its removal diagnostic, reserved `<scene>` tag name, `sprite.costume`-never-emitted note (now emitted, D4), `provenance.injected`, and the inert `# title` (frontmatter `title:` is the title). |
| D14 | Case | Authoring attrs and keys are lowerCamel; the audit found no multi-word lowercase key to rename, so this is a stated rule plus a checker test. |
| D15 | Migration | `lute fix` gains every mechanical rename (directives, attrs, tags, line `id=` → a preceding `::label{name}`, `<match on>`, choice `label`). Old spellings get diagnostics naming the new form (`RENAMED_ATTRS` style; add a renamed-directive table). Lossy cases — camera numeric fields, `cut full`, missing POV — are diagnosed, not guessed; the corpus owner migrates them by hand. |

## Deferred

- `<timeline>`/`<track>`: 27 uses in 5 files — not dead. Decide its relation to sequence references before touching it.
- Overloaded core nouns (`scene`, `beat`, `entry`, `on`, `use`): decide with the concept model (D7 of the ADR), not as renames.
- Camera persistence, sequence bound characters: wait for a runtime consumer.
- Timeline ordinal identity: only `barrier` reads it, within one IR; no saved or cross-build consumer.
