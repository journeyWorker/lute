# Lute 0.42.1 — tooling and hygiene patch decisions

Owner decision, 2026-10-14, taken after the 0.42.0 release (`f7bc6dcc`) from a
review of the repository against [blessed.rs](https://blessed.rs/crates), the
owner-provided AI-agent CLI research report, and the
release's own one-release obligations.

## Scope decision

0.42.1 is a **tooling and hygiene patch**. No language, IR, Event/snapshot or
bindings behaviour changes. The bodies of
`schemas/lute-{ir,events,snapshot,player-bindings}-0.42.schema.json`,
`packages/runtime/src/generated/**` and `packages/player/src/bindings/schema.ts`
stay byte-identical; `bindingsVersion` stays `"0.42"`. Every visible axis
stamps `0.42.1` under the alignment policy.

## In-scope decisions

| Item | Decision | Why |
|---|---|---|
| rustfmt | Adopt rustfmt with its **default** configuration (no `rustfmt.toml`), formatted by the CI-pinned toolchain. One formatting-only commit, listed in `.git-blame-ignore-revs`; CI fails on `cargo fmt --all --check`. | The tree was never formatted: default rustfmt rewrites 408 of 701 Rust files (~18.6k diff lines), and every wider/heuristic configuration measured rewrites more (50k–105k lines), so the code is closest to the default style. No branch or PR is open, so the one-time churn has no merge cost now. The 0.9-era "never run repo-wide `cargo fmt`" rule existed only because the tree was unformatted. |
| CLI help | Each subcommand's summary in `lute --help` is one short sentence; the existing detail stays in that subcommand's `--help`. `lute fix`'s text names the migrations it performs today. | `lute --help` is 10.4 KB because whole paragraphs are used as summaries; the report's "short synopsis, targeted detail" rule is the cheapest token win for agent callers. |
| Bun/tsc comparison | Remove `scripts/compare-typecheck.sh`, its fixtures, the three CI steps and the paragraphs documenting it. `bun check` stays the package typecheck. | 0.42.0 decided the comparison runs for that release only. |
| Repository hygiene | Untrack `scripts/__pycache__/*.pyc` and ignore `__pycache__/`; correct `status:` markers of design/plan/note documents whose work has shipped or been superseded. | Committed bytecode and stale `Draft` markers misreport the repository. |

## Explicitly out of scope (0.43)

`serde_yaml` (deprecated upstream) → `yaml_serde`; a structured JSON error
envelope for usage/I/O failures in `--json` mode; `lute schema` command
introspection; a common JSON envelope across commands; output projection.
They change public CLI/JSON contracts or need a dependency migration review and
get their own spec.
