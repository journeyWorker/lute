## Working rules

- **One Rust owner at a time**, in the main checkout, in the order below.
  TS/docs slices run in worktrees and the orchestrator merges them.
- **Coding rules.** `docs/design/rust-coding-rules.md` is Accepted. Every Rust
  slice reads it first and writes **new** code to it. Existing code is not
  swept (0.50).
  - The note rules out a HIR / consuming-tree Fold for 0.50. `fold_env`
    (environment construction) and the ProjectVocab/DocOverlay split are not
    that, so A1 proceeds.
  - If a later revision of the note introduces a HIR/Fold pipeline that this
    design would have to build on, A1 stops. It records the blocker in the
    progress log and reports to the orchestrator.
- **Reviewer pass per slice**, against its spec sections. Findings are fixed
  before the next dependent slice starts.
- **Regression test per change**, failing on the base (`$SNAP/lute-0.48.1`, or
  the change reverted). The slice records how this was shown.
- `cargo fmt --all` before each Rust commit. `cargo clean` only by the
  orchestrator, between slices. **Never** `--release`, `cargo doc` or
  `include!`.
- Never hand-edit generated output. Bless registry pages with
  `LUTE_BLESS_DIAGNOSTICS=1` and review the diff.
- Historical records are never rewritten.
- Out-of-scope bugs: `gh issue create --label bug` with evidence,
  immediately, and a line in the log.
- Commit per slice (`feat(0.49): <slice> - …`) and per milestone. The tree is
  clean at handoff.

   the stage order. Base diagnostics are spliced at their 0.48.1 positions,
   re-anchored.
3. `DocOverlay` records its **changed set**: domains/kinds/labels it changes,
   imported paths/defaults it refines, defs it declares. Each stage follows
   the §9.2 table:
   - domain-dependent base paths are recomputed when their domain changes
     (R1);
   - the clock stage is recomputed on effective state when its decls, paths,
     defaults, domains or invalid rows change (R2);
   - all imported defs are re-settled when inline defs exist (R3).
4. `StateView` replaces every `.decls` access.
5. `RelVocab`/`domains` are shared through `Arc`, or merged as in 0.48.1
   when changed. `desugar_document` stops cloning domains.
