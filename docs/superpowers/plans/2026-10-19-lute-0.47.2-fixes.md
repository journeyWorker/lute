## Working rules

As 0.47.1's plan: one owner per file set; every slice ends with a reviewer pass; every fix has a
regression test that fails on the base; the 0.47 Testing rule (real runtime output / browser suite over
compiled bundles, no hand-written view or record); EN and KO docs in the same slice; `cargo fmt --all`;
`cargo clean` only between slices by the orchestrator; never `--release`, `cargo doc`, `include!`. No
contract generator runs (no schema or generated-TS change). `llms-full.txt` is synced once, in Z, for
pages it mirrors.
