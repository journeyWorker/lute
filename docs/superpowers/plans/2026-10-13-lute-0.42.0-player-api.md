`jq`, `gh`, Bun 1.4.3, wasm-bindgen-cli 0.2.126, Playwright Chromium and

## Working rules

- One Rust owner at a time: R1 → R2, then C; no concurrent Rust edits.
- TypeScript slices start only after the Rust contract is final and the single
  G1 generation slice has landed. Disjoint TS slices MAY then run in parallel.
- Every slice ends with a reviewer-agent pass against its spec sections. Fix
  all findings before the next dependent slice begins.
- Add a regression test that fails on the merged 0.41.1 base before each fix.
- Commit each completed slice; the orchestrator owns integration and release
  commits. Keep the worktree clean at every handoff.
- Generated JSON schemas are owned by the Rust slice that changes their source
  types. All generated TypeScript is owned only by G1 (then Z's stamp/rename
  rerun). Never hand-edit generated output.
- Never use `cargo clean` while anything builds; only the orchestrator MAY use
  it between slices after confirming no build is running. Never use
  `--release`, `cargo doc`, or `include!`.
- Every changed user surface gets English and Korean documentation in the same
  slice. Keep tests and fixtures close to the owning implementation.

## T1 — player API and runtime-facing behavior (#70, #77, #79, #80)

**Owned files:**

- `packages/player/src/{LutePlayer.ts,model.ts,ports/index.ts}`;
- `packages/player/src/{cues/index.ts,director/index.ts,session/index.ts}` and
  any narrow machine event wiring;

  safety, snapshots/restores, Director host-plugin precedence/parity, and
  voice replay with distinct line/voice keys;
- English/Korean player architecture, bindings, controls and API docs.

**Implementation order inside T1:**

1. Change cue factory construction to expose `cueFactory(base)`, preserving
   the one-cue/event invariant and applying the wrapper exactly once.
2. Make the Director's default construction use the same factory path and merge
   `host.plugin` with explicit precedence (host map wins duplicate tags).
3. Expose `snapshot: Effect.Effect<SaveRuntime, Errors.RuntimeRejection>`;
   capture runtime snapshot/log/backlog, with stage in the runtime continuation,
   and do not capture presenter/timer/overlay state.
4. Add `voiceKey` to replay flow and resolve exactly that key; keep lineId only
   for identity/display.
5. Replace numeric `musicVolume` parsing by `bindings.volumes` lookup. Absent
   volume is gain 1; an unmapped present member is gain 0.

**Acceptance (after G1):**

## D — Bun checks and CI (#68)

**Owned files:** `packages/{runtime,player,player-web}/package.json`, all
`.github/workflows/*.yml` Bun pins and typecheck steps, new checked-in
`scripts/compare-typecheck.sh`, its fixture/test, and English/Korean tooling
and CI documentation.

Change each package's `typecheck` to `bun check`; leave `build`'s declaration
`tsc` invocation. Pin every workflow to Bun 1.4.3. For this release only,
`scripts/compare-typecheck.sh <package-dir>` creates `tmp=$(mktemp -d)` with
`trap 'rm -rf "$tmp"' EXIT`, runs `bun check --no-pretty --all -p <package-dir>`
and `bunx tsc --noEmit --pretty false -p <package-dir>` while capturing each
output and status, normalizes both streams with the single regex
`^(.+)\(([0-9]+),([0-9]+)\): error (TS[0-9]+): (.*)$` to sorted unique
relative `path:line:column TSdddd` records, ignores Bun's `Found N errors in
M file(s), checked K files [...]` summary, prints statuses and a unified diff,
and fails when statuses or sets differ. `--no-pretty --all` is mandatory:
Bun's default output is environment-dependent (pretty terminal versus
agent XML-like output), and without `--all` identical errors after the first
50 are grouped. These flags force tsc-compatible lines in every CI
environment. It runs in the runtime, player and player-web CI jobs. Keep
launcher `tsc` where its declaration/no-emit job is independently required.
Add a fixture whose expected diagnostic is
`a.ts(1,14): error TS2322: Type 'string' is not assignable to type 'number'.`
and therefore yields one equal record from both commands, plus mismatch and
empty-set command-failure cases.

**Acceptance:** all three package scripts pass under Bun 1.4.3; CI YAML has no
1.4.2 pin; the helper is executable and its equal/mismatch/failure fixtures
behave as specified; `build` still emits declarations. Do not add a second
permanent typecheck convention.
