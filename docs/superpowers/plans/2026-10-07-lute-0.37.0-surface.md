# Lute 0.37.0 — surface cleanup: implementation plan

- **Spec:** `docs/proposals/scenario-dsl/0.37.0.md`
- **Direction:** D6 clean cutover; S1–S6 and D1–D15 in the 2026-10-07 surface decision log
- **Base:** branch `feat/0.37`, release 0.36.6
- **Cutover:** no aliases, compatibility modes, legacy IR fields, or old command kinds after the release
- **Scope:** parser/checker/compiler/runtime/CLI, schema, tree-sitter, LSP, dogfood and conformance corpus, docs/website, diagnostics, version stamps

All Rust slices are strictly sequential: S1 → S2 → S3 → S4 → S5 → S6 → S8 →
S11 → S12 → S13. A producing slice owns its complete downstream-callsite
closure across `lute-check`, `lute-compile`, `lute-trace`, `lute-model`,
`lute-lsp`, `lute-cli`, `lute-bench`, and tests whenever its public change
breaks those callers; no later slice starts with a broken workspace. One owner
edits a crate's module wiring at a time. S7 is non-Rust and runs after S2 makes
the core capability snapshot final. S9/S10 are corpus/docs slices, not Rust
API waves. Every dependent slice starts only after the prior slice's reviewer
has signed its gate.

Every Rust worker runs the full workspace acceptance before yielding:

```sh
RUSTFLAGS="-D warnings" cargo check --workspace --all-targets
cargo nextest run --workspace
```

Before S12, the only permitted nextest failures are the frozen-output readers
`lute-cli::conformance`, `lute-compile::e2e`,
`lute-compile::component_fold::existing_goldens_untouched`, and
`lute-compile::round_trip`; these read old checked-in corpus/golden JSON and
are explicitly restored by S12. No other test or warning may be red.

No slice uses `include!` stitching, a `--release` build, or `cargo doc`.
Workers never run `cargo clean`; the orchestrator runs it between slices, only
while nothing is building, to keep `target/debug` small.

S9 authored corpus migration runs after S5 and before S10/S12.
S10 owns every current Markdown/MDX/mirror after S9.

Rust slices never overlap. Each producing slice updates the complete downstream
caller closure that its public API breaks, in the same slice, and runs the
workspace gate before its reviewer pass. S12 is the only owner of
`artifact.json`/`expected.json` regeneration.

## S1 — syntax AST, sections, and inline modifier grammar

**Depends on:** G0. **Owns:** `crates/lute-syntax` plus every direct
downstream caller broken by the AST/parse contract in `crates/lute-check`,
`crates/lute-compile`, `crates/lute-model`, `crates/lute-trace`,
`crates/lute-lsp`, `crates/lute-cli`, `crates/lute-bench`, and their tests.
No later slice may repair an S1 compile break.

**Files owned:**

- `crates/lute-syntax/src/ast.rs`
- `crates/lute-syntax/src/parser.rs`
- `crates/lute-syntax/src/parser/line.rs`
- `crates/lute-syntax/src/parser/tests.rs`
- `crates/lute-syntax/src/lib.rs` and module wiring
- `crates/lute-syntax/Cargo.toml` only if a parser test dependency is required

**Change:**

1. Rename the AST/source-unit vocabulary from shot to section without changing
   the `##` body boundary. Parse the exact trailing `{#id}` suffix and preserve
   heading text without it. Reject duplicate ids in the checker-owned pass, not
   in the parser.
2. Add an ordered inline modifier representation below the current opaque line
   text and interpolation scan. Implement the grammar, nested spans, escapes,
   pause/speed syntax, and precise source spans. Keep `{{…}}` interpolation
   markers and `\{{` literal behavior intact.
3. Add AST support for the new names (`cg`, `actor`, `jump`, `label`,
   sequence), choice `text`, match `subject`, reward `id`, and line-label
   migration spans. Old syntax must remain parseable only far enough to produce
   the named migration diagnostic/fixit; it must not enter the 0.37 AST as a
   valid surface.
4. Update parser unit fixtures for malformed nesting, escaped punctuation,
   interpolation inside spans, empty segments, section suffixes, and old-form
   diagnostics.

**Acceptance:**

```sh
RUSTFLAGS="-D warnings" cargo check --workspace --all-targets
cargo nextest run --workspace
```

**Review gate:** syntax reviewer checks byte spans, nesting termination, escape
precedence, no interpolation regression, and that no compatibility AST aliases
remain. S2 and S7 cannot start until this gate is signed.
