# Lute Scenario DSL — 0.17.2: Additive Plugin Owner IR Metadata

- **Version:** 0.17.2
- **Status:** Draft (alignment revision of 0.17.1)
- **Date:** 2026-09-18
- **Scope:** no grammar production or static-semantic change. The compiled IR adds optional owner metadata to passthrough plugin records; all authoring semantics remain unchanged.

## 1. Language surface

Lute 0.17.2 accepts exactly the same source documents as 0.17.1. There are no new directives, attributes, diagnostics, control-flow forms, or expression rules. A `luteVersion: "0.17.1"` document has the same semantics after mechanical restamping to `0.17.2`.

## 2. IR surface

A passthrough plugin command MAY carry an optional `plugin` string containing the resolved owning plugin package id. The existing `kind: "plugin"`, `tag`, `fields`, `effects`, stamp fields, and addressing rules are unchanged. The new field is append-only and consumers MUST ignore it when they do not need owner-aware dispatch.

Presentation directives that declare `lower: { record: ... }` continue to emit the corresponding stable core record kind. The owner field applies to passthrough plugin records, not to core records.

The published schema remains [`lute-ir-0.17.schema.json`](../../../schemas/lute-ir-0.17.schema.json); the IR major line is unchanged and the field is compatible with the existing unknown-field rule.

## 3. Version alignment

The toolchain, language, and IR visible version axes all present `0.17.2`. The language axis is an alignment-only restamp. The IR axis has an additive field and remains compatible for consumers that already accept the 0.17 major line.
