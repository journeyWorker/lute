# 포맷팅 규칙 (0.41.0)

`lute fmt <path>…`는 의미를 바꾸지 않고 소스를 표준화합니다. 결정적이며 멱등적입니다. `--check`는 아무것도 쓰지 않습니다. 종료 0은 표준 형식임을, 1은 선택한 파일이 바뀔 것임을, 2는 I/O, UTF-8 또는 파싱 실패임을 뜻합니다.

포맷팅은 `.lute` 문서와 Lute가 소유한 프로젝트, 스키마, 설정된 플러그인 YAML 입력에 적용됩니다. 들여쓰기, 간격, 줄 끝, 구분자, 소스 레이아웃 같은 사소한 요소를 정규화하면서 주석, 작성된 문자열, 줄 ID, 의미 순서, 값을 보존합니다.

YAML 값은 불투명합니다. 포매터는 임의의 YAML을 다시 직렬화하거나 값을 다시 쓰지 않습니다. 심볼릭 링크는 건너뜁니다. 포맷팅은 검증이나 컴파일이 아닙니다. 진단에는 `lute check` 또는 `lute check --project .`를 사용하세요.
